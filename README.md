# Telegram-бот для приюта животных
#### Этот проект представляет собой Telegram-бот, разработанный для взаимодействия с приютом животных. Он предоставляет пользователям информацию о приюте, процессе усыновления и уходе за животными, а также позволяет усыновителям отправлять отчёты о своих питомцах. Волонтёры могут управлять списком животных и усыновлениями через специальное меню.
## Возможности
#### Информация о приюте: Пользователи могут узнать адрес, расписание работы, правила безопасности и контактные данные приюта.
#### Инструкции по усыновлению: Предоставляет информацию о том, как взять животное, включая список необходимых документов, рекомендации по транспортировке и обустройству дома для разных типов животных.
#### Усыновление животных: Пользователи могут просмотреть доступных животных и начать процесс усыновления, выбрав животное по его ID.
#### Отчёты о питомцах: Усыновители могут отправлять ежедневные отчёты (фото, рацион, самочувствие, поведение) в течение испытательного срока, которые сохраняются и пересылаются волонтёрам.
#### Меню волонтёра: Администраторы (волонтёры) могут добавлять/удалять животных и просматривать информацию об усыновлениях.
#### Сбор контактных данных: Пользователи могут оставить свои контакты, которые проверяются по шаблону номера телефона.
#### Интеграция с базой данных: Использует JPA (Java Persistence API) для хранения и управления данными о пользователях, животных, усыновлениях и отчётах.
